# Simple Contact Form

This is a simple web app that allows users to submit a contact form with their name, email, and message. It features a front-end built with HTML, CSS, and JavaScript, and a back-end server built using Node.js and Express.

## Files:
- *index.html*: Contains the form.
- *style.css*: Styles for the form.
- *script.js*: Handles the form submission using JavaScript.
- *server.js*: A Node.js backend to handle form submissions.
